# Sysuew · HTML-учебник

Один академический электронный учебник для 6 дисциплин. В части **«Численные методы»** доступна лекция о методе Гаусса и методе простых итераций с подробными математическими выводами и пояснениями. **Практикума, лабораторных работ и исходных сканов в архиве нет.**

## Чтение

Откройте файл `site/index.html` в браузере. Формулы отображаются встроенной поддержкой MathML современных браузеров; интернет не нужен. В книге работает поиск, оглавление и тёмная тема.

## Редактирование

Главы хранятся в `subjects/numerical-methods/lectures/*.qmd`. Для пересборки требуется Pandoc:

```bash
sudo apt install pandoc
python3 tools/build_site.py
```

## Публикация в интернете

`site/` — полностью статический сайт, который можно разместить на GitHub Pages, Netlify, Cloudflare Pages или обычном хостинге. Публичный URL появляется **после** загрузки файлов на выбранную площадку. Сам по себе локальный HTML-архив не размещён в интернете.
