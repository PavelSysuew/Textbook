# Единый университетский HTML-учебник — правила пополнения

1. В проекте шесть предметов: численные методы, ТВиМС, криптография, машинное обучение, базы данных, компьютерная графика.
2. Новый материал добавлять только в нужный предмет. Разбор лекций на русском языке, без сокращений исходных определений, формул и преобразований.
3. Не заменять обозначения преподавателя на привычные аналоги; сохранять буквы, индексы и порядок. Если исходная запись математически неверна, рядом давать отдельный блок исправления с объяснением.
4. Сложные переходы объяснять пошагово. Дополнительные выводы и численные примеры отмечать как пояснение; не выдавать их за авторский текст.
5. Конспекты — .qmd (Markdown + LaTeX). У каждой главы единый дизайн, заголовок, один раскрывающийся блок «На этой странице» и корректные SVG-графики. Если в присланной лекции есть ручное «Содержание», сборщик переносит его в этот блок и не дублирует в тексте. Новые сканы исходных страниц в итоговый HTML не помещать.
6. Практикумы, исходный код лабораторных, задания и PDF не создавать без отдельного запроса.
7. Для сборки использовать `python3 tools/build_site.py` при наличии Pandoc. Готовая книга в `site/`; в браузере открывать `site/index.html`.
8. Не переписывать HTML/CSS заново при каждой главе. Изменять только нужный .qmd и обновлять book.json. Книгу можно опубликовать на статическом хостинге (GitHub Pages/Netlify) без серверной части.
